Mew is an agent harness designed for your work.

mew gives you a place to work with agents you can configure. Choose a model, give it instructions, and decide which tools it can use.

Get started with mew → View on GitHub

mew is experimental and under active development.

01

Give it a task.

Ask mew to explore a codebase, investigate a problem, or make a change. It can search and read files, edit them, and run commands as the work takes shape.

You can follow along, answer questions, and change direction at any point.

02

Bring in another agent.

Give a subagent a focused task while mew continues working. Ask for an investigation, a review, or a second perspective on a plan. The subagent reports its result back to the conversation.

You can give subagents their own instructions and choose which models and tools they use.

03

Make an agent for the job.

Personas let you give an agent a role and its own instructions. You might set up one for coding, one for research, or one that’s just there for conversation.

Each persona can use a different model and tool set. Give a coding persona access to the shell, or leave tools off entirely.

04

Choose when mew asks.

Set permissions for the actions you want to review. You can configure rules for tools, commands, and paths, then choose a permission mode that suits the work.

05

Give it context that carries forward.

Add project instructions and reusable skills for the things you do often. Mew can load them into a conversation as needed.

Your sessions are saved locally, so you can return to a conversation and see what happened.

06

Start with a model and a task.

Choose a supported provider, open a session, and tell mew what you want to work on.
