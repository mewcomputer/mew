Mew is a coding agent for your terminal.

Run mew from a project directory with a model provider you’ve configured. It can read the repo, edit files, and run commands with the permissions you set.

Install mew → View on GitHub

mew is experimental and under active development.

01

See what it ran

Ask Mew to find where an error comes from. It can search for the message and follow it back to the call site. If it runs a test, the command and its output show up in the chat.

02

A second set of eyes

Give a subagent a diff to review while Mew keeps working. The reviewer works in its own conversation and sends its findings back. You can give it its own instructions and model.

03

From planner to builder

Ask the planner persona to write a plan, then switch to the builder to work through it. For a persona of your own, put its instructions in PERSONA.md and set which model and tools it can use.

04

Approve a command once

A permission prompt shows the command before it runs. You can allow that call, allow the tool for the session, or deny it. For a command you run often, set an allow rule in config.toml.

05

The repo comes with instructions

Put project instructions in AGENTS.md. A procedure like preparing a release can go in a SKILL.md that Mew loads when needed. Use /sessions to reopen a saved chat.

06

Install mew

After installing, follow the guide to set up a model provider. Run mew from the repo you want to work in.
