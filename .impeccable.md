## Design Context

### Users

Primary users are developers working in a local coding workspace on macOS. They
move between multiple agent sessions and project directories, often while
several sessions are running or waiting for permission, input, or a review.
The product should help them keep their place, respond to attention quickly,
and inspect or change the workspace without losing the main conversation.

### Brand Personality

Fast, focused, alive. The interface should feel immediate and high-signal,
with enough motion and state feedback to feel active without becoming noisy.

### Aesthetic Direction

An integrated coding workbench inspired by Codex-style composition: the main
conversation remains the primary surface, while navigation and contextual work
surfaces sit beside it as purposeful workspace regions rather than generic
dashboard sidebars. macOS is the first target. Dark and light themes remain
supported; the dark desktop reference is the current visual anchor.

### Design Principles

- Keep orientation visible: the active project, session, and attention state
  should be legible at a glance.
- Separate location from work: session navigation belongs to the pinned summary;
  browser, changes, review, and live activity belong to the contextual workbench.
- Preserve user control: the pinned summary and workbench open, close, and
  resize independently.
- Make attention actionable: questions, permissions, failures, and review work
  should surface with explicit labels and a direct next action.
- Favor keyboard-first, low-latency interactions with restrained motion and
  clear focus states.
