# Design context

mew is a coding assistant with a terminal-first workflow. The native GPUI app
is its companion: both clients should agree on projects, conversations,
progress, required actions, review, and follow-ups.

Keep the TUI's playful personality, cat, companion, and theme accents. Prioritize
clear task ownership and predictable behavior over changing its visual identity.
Power users should retain efficient keyboard navigation, editing, and progressive
disclosure of tools and reasoning.

Treat details as part of correctness. Popovers and modals need a distinct,
opaque raised surface. Paint the entire conversation canvas, including tool
edges and gaps. Long input, Unicode, small terminals, and empty searches must
remain usable. Never discard a draft or route a follow-up to another task.

Use the existing theme manifest and terminal renderer. Prefer small, tested
changes; discuss substantial architecture changes before implementing them.
