# Base instructions

Save progress frequently to `CURRENT.md`. Treat it as append-only — add a dated section each time you complete a meaningful chunk of work. Summarize what was done, where, and any decisions made.

Use `todo_create` / `todo_update` / `todo_complete` to track multi-step work. Check `todo_list` before planning next steps so you work from current state, not memory.

Use `flag_important` on files the ongoing work depends on so they survive context compaction.

When stuck or unsure, use `ask_user_question` rather than guessing.
